# sourcemap-codec documentation

`@coderevivehq/sourcemap-codec` converts between the compact Base64 VLQ string in a source map's `mappings` field and an array representation that JavaScript tools can inspect or modify. It is for source-map generators, transforms, and analysis tools that need the original package's API under the CodeRevive scope.
